# TGE Beta 1

First API-freeze release of the Terminal Game Engine.

## What's in it
- **Public C API (`include/tge/*.h`) frozen for Beta 1** — additive/consumer-driven
  changes only during the beta; final ABI/API compatibility is guaranteed at RC/1.0.
- **`tge-extra` remains experimental** (may break between minor versions).
- **`bindings/cpp/` is an ergonomics lab**, excluded from the stability policy
  (frozen at "C++ 1.0" with 4 probes / 125 tests).

## Verification (reproducible via the Makefile)
- `make test`: 34 test suites, 0 failures (header self-containment + no-malloc check).
- `make games`: 13 games build.
- `make examples`: 9 minimal examples build.
